## 📖 About the Repository

This repository is a structured documentation of my **web development learning journey**, progressing systematically from core web technologies through full-stack application development. Each folder represents a distinct phase in the learning process, with practical implementations, mini-projects, and hands-on exercises.

The learning path follows industry-standard progression:

- **Foundation**: HTML, CSS, JavaScript fundamentals
- **Intermediate**: DOM manipulation, async operations, APIs
- **Backend**: Node.js, Express.js, middleware concepts
- **Databases**: MongoDB with Mongoose, MySQL with relational models
- **Full-Stack**: Complete applications integrating frontend and backend

## 🚀 Getting Started

### Prerequisites

- **Node.js** (v14.x or higher) - [Download here](https://nodejs.org/)
- **npm** or **yarn** - Comes with Node.js
- **Git** - For version control
- **MySQL** (for MySQL-based projects) - [Download here](https://www.mysql.com/downloads/)
- **MongoDB** (for MongoDB projects) - [Download here](https://www.mongodb.com/try/download/community) or use MongoDB Atlas

### Installation Steps

1. **Clone the Repository**

   ```bash
   git clone https://github.com/yourusername/web-development-journey.git
   cd web-development-journey
   ```

2. **For Frontend-Only Projects (HTML, CSS, JavaScript)**
   - Simply open `.html` files in your browser
   - Or use [Live Server Extension](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) in VS Code

3. **For Node.js Projects**

   ```bash
   cd [project-folder]
   npm install
   npm start  # or node index.js
   ```

4. **For Express + Database Projects**

   ```bash
   cd [project-folder]
   npm install

   # Create .env file if needed (MySQL projects)
   cp .env.example .env
   # Update database credentials

   npm start
   ```

### Running Specific Projects

**Express + MongoDB:**

```bash
cd "MongoDB with Express"
npm install
# Ensure MongoDB is running
npm start
# Open http://localhost:3000
```

**Express + MySQL:**

```bash
cd MySQL
npm install
# Create .env file with MySQL credentials
npm start
# Open http://localhost:3000
```

**REST API:**

```bash
cd REST
npm install
npm start
# Test endpoints with Postman or Thunder Client
```

**JavaScript Mini Projects:**

- Navigate to `JavaScript/7.mini project/`
- Open `.html` files in browser to interact with Simon Says game or TODO app
